METHOD BEFORE METRICS

A reproducible comparison with explicit boundaries.

The system estimates associative discharge-time readmission risk from historical encounter data. It does not establish causality, replace clinical judgment, or claim readiness for patient care.

01

Patient-grouped evaluation

All encounters for one patient belong to exactly one train, validation, or test partition. Saved assignments are shared by every model and graph.

02

Patient-clustered bootstrap

{% if bootstrap.metadata %}{{ bootstrap.metadata.valid_replicates }} valid replicates resample complete test-patient clusters and use identical draws for paired model comparisons.{% else %}Complete patient clusters are resampled with common draws for every model.{% endif %}

03

GCN seed stability

{% if seed_stability.metadata %}The primary seed remains {{ seed_stability.metadata.primary_seed }}; {{ seed_stability.metadata.number_of_seeds }} deterministic runs quantify training variability without best-seed selection.{% else %}Prespecified seeds quantify training variability without best-seed selection.{% endif %}

04

Repeated perturbations

{% if robustness_summary %}Graph removal and noise scenarios contain {{ robustness_summary[0].number_of_trials }} recorded evaluations each, with trial-level results and uncertainty intervals.{% else %}Graph removal and noise scenarios use repeated recorded perturbation seeds.{% endif %}

05

PCA sensitivity

{% if pca_analysis.selected_components %}Component count {{ pca_analysis.selected_components }} was selected using validation PR-AUC, not the test set.{% else %}Component count and kNN settings are chosen using validation evidence only.{% endif %}

06

Graph ablation

Original, identity-only, matched-random, and feature-shuffled conditions test neighbour contribution and feature–graph alignment. No model is retrained on test data.

07

Class imbalance

Early readmissions are uncommon. PR-AUC, recall, balanced accuracy, validation-selected thresholds, and confidence intervals accompany accuracy.

08

Warshall boundary

O(V³) closure is used only for a five-entity reachability demonstration, never on the full hospital graph or for prediction.

09

Non-causal associations

Edges and coefficients may reflect documentation, access, care pathways, and dataset biases. They do not prove clinical mechanisms.

10

No clinical validation

Historical US data from 1999–2008 may not transfer to current institutions or populations. Prospective and external validation are absent.

Responsible interpretation

Use this application for education and research review only. Do not use outputs for diagnosis, treatment, triage, denial of care, or other decisions about real people.
